🐾 Pawsitively Adorable Pets GallerA simple and visually pleasing image gallery that showcases some of the cutest pets 🐶🐱🐰.
Built using pure HTML and CSS, this project focuses on design, layout, and smooth visual effects.

🌟 About This Project

This project is part of my learning journey in web development.
After understanding core concepts of HTML and exploring CSS features like transitions and gradient backgrounds, I decided to build something on my own.

Unlike my very first basic project (which was tutorial-based), this gallery is completely self-created.
It may look simple, but it represents my practice, consistency, and improvement.
